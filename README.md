# Согласиус

Адаптивная страница по предоставленному скриншоту `index_01.png` (1672 × 3628). HTML, SCSS, JavaScript; сборщик Vite. Требуется Node.js 20.19+ или 22.12+.

## Запуск

```sh
npm install
npm run dev
```

Адрес разработки: http://localhost:5173 (если порт занят, Vite выведет другой).

```sh
npm run build
npm run preview
```

Готовая сборка находится в `dist/`.

## Файлы

```text
index.html            Семантическая структура страницы
src/
  styles.scss         Переменные, компоненты, адаптивные стили
  main.js             Вкладки, меню, модальные окна, формы

package.json          Зависимости и команды Vite
package-lock.json     Зафиксированные версии зависимостей
.gitignore
README.md
```

## Реализовано

- Шапка, первый экран с роботом, преимущества, логотипы клиентов, блок ролей и блок трёх шагов.
- Компоновки для компьютера, планшета и телефона.
- Переключение пяти вкладок мышью и клавишами ← / → / Home / End, раскрытие подробностей, мобильное меню.
- Диалоги регистрации, входа, подключения и тарифов. Нативная проверка email и обязательного пароля при входе; закрытие по Escape, кнопке и фону; нативное удержание фокуса в диалоге.
- Видимый фокус, ссылка перехода к содержимому, семантические заголовки, текстовые альтернативы изображениям, учёт reduced motion.

## Исходные материалы и допущения

- Предоставлен только плоский скриншот. Логотип, робот, пиктограммы, логотипы клиентов и скриншот кабинета показаны через CSS-кадрирование исходника без перерисовки. Внутренние `img` имеют пустой `alt`, а смысловое описание задано родительскому `role="img"` через `aria-label`, чтобы не озвучивать подпись дважды. Пиктограммы декоративные.
- Не хватает отдельных SVG/PNG/WebP этих изображений, файлов оригинального шрифта и его точного названия. Указан стек Montserrat / Arial / sans-serif; без установленного Montserrat используется Arial. Это влияет на точность типографики. Сеть и сторонние шрифтовые сервисы для работы страницы не нужны.
- Мобильный макет отсутствует: на телефоне робот перенесён под описание, элементы расположены колонкой, роли прокручиваются горизонтально, навигация свёрнута в меню.
- В блоке «Подключение в 3 шага» в исходнике заполнен только первый серый блок. Остальные оставлены пустыми, сохранено нижнее свободное пространство. Это статические блоки, не кнопки.
- Тексты четырёх неактивных вкладок и раскрываемых подробностей, вид диалогов и мобильного меню предложены для демонстрации: в исходнике их нет.
- Нет цен, адресов личного кабинета, API авторизации и обработки заявок. Тарифы показывают информационное окно; формы не передают и не сохраняют данные, не создают аккаунты. Успешная локальная проверка формы явно обозначена как демонстрация.
- Для точной финальной доводки нужны исходные ассеты, шрифт и содержимое незаполненных состояний.

## Проверки

- `npm install`: зависимости установлены, аудит не обнаружил уязвимостей.
- `node --check src/main.js`: синтаксис JavaScript проверен.
- `npm run build`: production-сборка выполнена успешно.
- `npm run dev`: сервер запускается; страница, JavaScript, SCSS и изображение доступны по HTTP.
- Браузер в окружении недоступен. Визуальное сравнение, реальные взаимодействия и адаптивность в браузере не проверены.
